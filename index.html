Abstract

Iterative Deepening A* (IDA*) is a graph search algorithm used to find the shortest path from a starting node to a goal node. It combines the space efficiency of Depth-First Search (DFS) with the optimality of A* search.

The algorithm repeatedly increases a cost threshold until the goal node is reached.

Introduction & Formula

IDA* evaluates nodes using the evaluation function:

$$f(n) = g(n) + h(n)$$
  • g(n): Cost from start node to current node.
  • h(n): Estimated cost from current node to goal (heuristic).
  • f(n): Total estimated path cost through current node.
Algorithm Steps
  1. Start from the initial node.
  2. Calculate $f(n) = g(n) + h(n)$.
  3. Set initial cost threshold $T = f(\text{start})$.
  4. Perform Depth-First Search (DFS) bounded by threshold $T$.
  5. If $f(n) > T$, prune node and record minimum $f(n)$ that exceeded $T$.
  6. If goal found, return success path.
  7. If search fails, set new threshold $T = \text{min exceeded } f(n)$ and repeat.
Complexities

Time Complexity: O(bd)

Where $b$ = branching factor and $d$ = depth of the solution.

Space Complexity: O(d)

IDA* uses significantly less memory because it stores only the current active path (like DFS).

Pros & Cons

Advantages

  • Uses low memory $O(d)$.
  • Combines efficiency of DFS and optimality of A*.
  • Guarantees optimal solution with an admissible heuristic.

Disadvantages

  • Nodes near root may be visited multiple times across iterations.
  • Can be slower than standard A* when memory is plentiful.
  • Performance heavily depends on heuristic quality.
Conclusion

IDA* is a memory-efficient and effective heuristic search algorithm. By replacing A*'s priority queue with iterative deepening DFS, it reduces space requirements from exponential $O(b^d)$ to linear $O(d)$, making it ideal for massive state spaces like 15-Puzzle or Rubik's Cube.
