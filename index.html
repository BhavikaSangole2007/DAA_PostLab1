Iterative Deepening A*

Interactive Algorithm Visualizer

Abstract

Iterative Deepening A* (IDA*) is a search algorithm used to find a path from a starting point to a goal. It combines the memory efficiency of Depth First Search with the heuristic guidance of A*.

The algorithm repeatedly increases a cost threshold until the goal is found.

Introduction

IDA* uses the following evaluation function:

f(n) = g(n) + h(n)
g(n) Cost from the start node to the current node.
h(n) Estimated cost from the current node to the goal.
f(n) Total estimated cost.

IDA* searches deeply like DFS but stops when the cost exceeds the current threshold.

Algorithm

  1. Start from the initial node.
  2. Calculate f(n) = g(n) + h(n).
  3. Set an initial threshold.
  4. Perform Depth First Search (DFS).
  5. If f(n) is greater than the threshold, stop exploring that node.
  6. If the goal is found, return the solution.
  7. Find the smallest f-value that exceeded the current threshold.
  8. Set this value as the new threshold.
  9. Repeat the search until the goal is found.

Time Complexity

O(bd)

Where:

  • b = branching factor
  • d = depth of the solution

IDA* may visit some nodes multiple times because it repeatedly performs the search.

Space Complexity

O(d)

Where d represents the depth of the solution.

IDA* uses less memory because it mainly stores the current path instead of keeping all explored nodes.

Advantages

  • Uses less memory.
  • Combines benefits of A* and DFS.
  • Useful for large search problems.
  • Can find an optimal solution with a suitable heuristic.
  • Simple and memory-efficient.

Disadvantages

  • Nodes may be visited repeatedly.
  • Can be slower than A*.
  • Performance depends on the heuristic function.
  • A poor heuristic can increase search time.

Conclusion

IDA* is a memory-efficient search algorithm that combines the heuristic idea of A* with the depth-first search strategy.

It repeatedly increases the threshold and searches until the goal is found. It is useful when the search space is large and memory is limited.
